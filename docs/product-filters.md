# Фильтры состояния товара и поставщика

В каталоге добавлены два независимых фильтра:

- «Состояние товара»: все товары, новые, б/у (секонд)
- «Поставщик»: все поставщики, постоянные, непостоянные

Фильтры работают совместно с поиском, категорией, полом, брендом, размером и ценой. Например, сочетание «Б/у (секонд)» и «Постоянные» показывает секонд постоянных поставщиков. «Сбросить» очищает оба новых фильтра вместе с остальными.

Состояние определяется по `products.isSecondhand`. Для старых карточек без boolean-поля сохраняется действующая классификация: постоянный поставщик — новый товар, остальные — секонд. Явное значение true/false имеет приоритет. Фильтр поставщика использует `isPermanentSupplier` независимо от состояния вещи. Документы Firebase не изменяются.

## Проверка

`npm run test:filters` проверяет настоящий интерфейс на синтетических товарах в памяти браузера: девять сочетаний, явные и отсутствующие поля, поиск, бренд, пустую выборку, сброс, возврат из редактирования. Запуски: ширины 1440 и 390, светлая и тёмная темы; дополнительно контролируются границы полей и отсутствие горизонтального переполнения страницы на 320 пикселях. Проверяется неизменность исходных товаров.

`node tests/product-filters.mjs --published` повторяет проверку опубликованной версии. Он не входит в рабочую учётную запись, блокирует Firestore и использует только синтетические данные в памяти. Результаты и снимки сохраняются в игнорируемой папке `output/filters/`.

Проверка включена в `npm test`; классификация отдельно проверяется через `npm run test:unit`.
